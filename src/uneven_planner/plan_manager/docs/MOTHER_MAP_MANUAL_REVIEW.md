# 8767 原始点云地图人工筛选（通用）

8767 是适用于各种点云地形的人工筛选页面。它显示 LAS/LAZ 原始点云，
保存你对候选区域的“通过/拒绝”判断。它不会因为程序自己的坡度规则擅自拒绝一张已经人工选好的地图。
`forest`、`desert`、`hill`、`snow` 等都只是任务名称，不会改变页面的点云查看和裁剪逻辑。

## 页面上的四步

### 1. 选择原始地图

“原始地图”就是下载的 `.las` 或 `.laz` 点云文件。

- 下载文件在当前电脑上：点“从电脑选择地图文件”，选择一个或多个文件。
  页面会自动把文件复制到项目的地图库，原文件不会被删除。
- 文件已经放在项目里：点“选择已有地图文件夹”，在目录列表中点进文件夹，
  再点“选择这个文件夹”。这只是读取已有文件，不会再次复制。
- “本次数据名称”只是给这批数据起一个名字，例如 `forest` 或 `desert`，用于自动整理文件。
  它不参与点云判断，也不是必须理解的算法参数。

导入后，顶部“当前原始地图”区域分成两个下拉框：先在“地形目录”选择 `forest`、`desert` 等一级目录，
再在“具体原始地图”中选择该目录下的来源和文件。左侧会显示当前加载了多少张地图。

### 2. 人工筛选并保存

在中间地图上拖动框选区域，右侧会显示二维点云和 3D 点云。拟合按钮使用候选区域内的全部点云，
只是辅助查看；再次点击可以在拟合结果和原始点云之间切换。最终是否通过由人判断。

点击“通过并保存”或“拒绝并保存”后，页面会自动保存一条标注记录。启动时通过
`--review-file` 指定的文件是：

```text
dataset/reviews/<本次数据名称>/manual_regions.jsonl
```

这份记录只保存判断、位置、旋转角度、统计信息和备注，不是地图文件，也不是最终训练数据。
页面正常工作不需要填写它的路径。只有换电脑、恢复旧工作或交接任务时，才打开“恢复以前的标注”。
“下载标注备份”可以把当前记录下载出来。

右侧“放入”选择的是训练集或验证集。它只决定通过的区域最后放到哪一组，不决定这个区域是否合格。

### 3. 生成训练用地图

点“生成训练用地图”。程序会把所有已通过区域转换成生成程序能直接读取的地图文件，
并自动写一份内部清单。操作者不需要知道这份清单的名字，也不需要手动移动文件。

页面里的“更改训练地图的保存位置”只在需要换输出目录时使用。
程序内部把这批中间地图称为 canonical map；这是实现名称，不是另一种地图，也不是必须填写的目录。

### 4. 生成最终训练数据

点“生成最终训练数据”。程序使用上一步的训练用地图，生成最终的：

```text
train/env*/map.p
train/env*/path_*.p
val/env*/map.p
val/env*/path_*.p
```

这些 `map.p` 和 `path_*.p` 才是拿去训练的最终数据。生成数量、最终保存位置和 ROS 端口
都已经有默认值，只有需要调整时才打开“调整生成数量或保存位置”。

## 启动页面

```bash
cd /home/sdu/uneven_planner
source /home/sdu/miniconda3/etc/profile.d/conda.sh
conda activate vim

python3 src/uneven_planner/plan_manager/scripts/serve_mother_map_review.py \
  --port 8767 \
  --title "原始点云地图人工筛选"
```

浏览器打开 `http://127.0.0.1:8767/`。

换一种地形时，在网页“地图”页修改“本次数据名称”并点击“确认”。如需继续已有标注，
在“审核”页加载对应的 JSONL；启动命令不绑定具体地形。

不在启动命令后面写地图目录也可以，之后直接在网页中导入或选择已有地图。
如果启动时已经知道项目里的地图目录，也可以把目录作为命令的最后一个参数传入。

## 文件位置说明

8767 当前使用仓库内的路径：

```text
dataset/external/<地形>/<来源>/raw  自动归档的原始 LAS/LAZ 文件
dataset/reviews/      人工通过/拒绝记录
dataset/canonical/    训练用地图中间文件，通常由网页自动管理
dataset/public_terrain_20m/  最终训练数据
```

原始地图的下载来源记录在：

```text
dataset/external/SOURCES.md
```

旧的 `/home/sdu/tmp/forest-mother-map-manual-review.jsonl` 和其他 `tmp` 目录内容只是历史文件或备份，
不是当前 8767 的默认输出位置。当前这轮 forest 标注记录是：

```text
dataset/reviews/forest/manual_regions.jsonl
```

8767 的“生成”页可以启动、打开和关闭 8765 结果查看器；8767 仍负责原始地图人工筛选和数据生成。

## 交接给其他人

交接时只需要告诉对方：启动 8767，点击“从电脑选择地图文件”，在地图上人工框选，
选择通过或拒绝，最后依次点击第 3 步和第 4 步。不要让对方手动创建 `tmp`、移动 JSONL、
填写服务器路径或猜 canonical 文件名。
